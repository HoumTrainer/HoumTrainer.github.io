# HoumTrainer — каталог упражнений

Сайт: https://houmtrainer.github.io/

- `catalog.json` — все упражнения и комплексы (создаётся в программе: Настройки → «Подготовить к публикации»).
- `klipy/` — клипы упражнений (mp4).
- `index.html` — страница со списком упражнений и комплексов.

Программа HoumTrainer читает `catalog.json` и скачивает из `klipy/` клипы новых упражнений.
